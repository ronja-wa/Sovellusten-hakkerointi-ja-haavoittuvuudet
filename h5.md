# [h5 It's Alive!](https://terokarvinen.com/application-hacking/#h5-its-alive-lari)

Tässä tehtävässä harjoitellaan GNU Debuggerin käyttöä.

## x) main.cpp

Ladataan main.cpp (Kurssin Moodle -sivulta). Se ilmestyy kotihakemistoon Downloads -kansioon.

    cd Downloads

    ls Downloads

Katsotaan ensin, miltä koodi näyttää microlla.

    micro main.cpp

Micro usein ilmoittaa helposti havaittavista virheistä. Tässä niitä ei näy ollenkaan.

<img width="527" height="1006" alt="image" src="https://github.com/user-attachments/assets/7b9f82d2-7693-4151-9b9a-03408edd2ae1" />

Ohjelman perusidea on siis se, että käyttäjältä pyydetään jokin luku, jonka kertoma (factorial eli n!) lasketaan ja tulostetaan.

Käännetään ohjelma ajettavaan muotoon siten, että sitä voi tarkastella GNU Debuggerilla.

    g++ main.cpp -g -o main-dbg

- g++ kääntää ohjelman C+ -kielestä koneelle ymmärrettävään muotoon.
- -g kääntää ohjelman siten, että sitä voi tarkastella GNU Debuggerilla.
- -o tallentaa tämän käännetyn tiedoston halutulla nimellä.

ls -komennolla nähdään, että main-dbg tiedosto ilmestyi.

Asennetaan GNU Debugger.

    sudo apt-get update

    sudo apt-get install gdb

Käynnistetään gdb.

    gdb ./main-dbg

gdb avautuu onnistuneesti.

<img width="1376" height="727" alt="image" src="https://github.com/user-attachments/assets/2b7d9b31-3965-4e2d-926f-b300f1d76d84" />

Komentoriville ilmestyy teksti (gdb), mikä tarkoittaa, että GNU Debuggerille voi syöttää komentoja.

Laitetaan main.cpp -lähdekoodi näkymään koko ajan.

    layout src

<img width="701" height="857" alt="image" src="https://github.com/user-attachments/assets/25ff4dfa-00e4-491f-a71e-0fcc27b82a5f" />

Kokeillaan ajaa ohjelma

    run
    
<img width="1081" height="240" alt="image" src="https://github.com/user-attachments/assets/ee7877e2-96c6-4bce-81f4-2efae1dfc351" />

Tuli ilmoitus, että ohjelma suoritettiin onnistuneesti, mutta siltä ei kuitenkaan tullut toivottua tulostusta.

Laitetaan breakpoint heti ohjelman alkuun, käynnistetään se ja käydään sitä läpi rivi kerrallaan ohjelman mukaisessa järjestyksessä.

    break main

    run

    step

    // step voidaan lyhentää komentorivillä s

<img width="462" height="168" alt="image" src="https://github.com/user-attachments/assets/3e117285-875c-4849-b6ed-a96caecd7213" />

cin>>n; -kohdassa kysytään käyttäjältä syötettä, joten laitetaan syötteeksi 5.

Rivillä 11 main -funktiosta siirrytään factorial -funktioon. step -komennon avulla päästään tarkastelemaan ohjelmaa rivi kerrallaan ohjelman suoritusjärjestyksessä, 
kun taas next -komennolla mentäisiin vain rivi kerrallaan eteenpäin.
