## x) Watch and summarize

### [John Hammond: GHIDRA for Reverse Engineering (PicoCTF 2022 #42 'bbbloat')](https://www.youtube.com/watch?v=oTD_ki86c9I)

- Ennen Ghidran käyttöä voi kokeilla:
  - ltrace = library call tracer
  - strace = trace system calls and signals
  - objdumb
- Asenna Ghidra ja siihen tarvittava java versio.
- Luo kansio ja lisää tutkittava tiedosto.
- Avaa CodeBrowser.
- Defined Strings -työkalun avulla on helppo etsiä pääohjelma.
- Decompiler kääntää koodin C-kielelle, mutta siellä voi olla määrittelemättömiä muuttujia sekä muuttujilla ja funktioilla ei ole selviä kuvaavia nimiä.
  - Nimet kannattaa muuttaa, jotta koodista tulee selkeämpi ja sen selvittämistyötä on helpompi edistää.

## a) Install Ghidra

Ghidra on NSA:n kehittämä ohjelmisto, jolla pystyy tekemään takaisinmallinnusta eli muuttamaan binäärin takaisin C-kieleksi.

Ghidran saa asennettua [NationalSecurityAgencyn GitHubista](https://github.com/NationalSecurityAgency/ghidra). Siellä on myös asennusohjeet, joten seurataan niitä.

Ghidran käyttö vaatii javan, joten se tulee asentaa etukäteen. Itsellä se oli jo asennettuna java 21

Ladataan [Releases -sivulta](https://github.com/NationalSecurityAgency/ghidra/releases) ghidra_12.0.2_PUBLIC_20260129.zip.

Downloads -hakemistoon ilmestyy zip-tiedosto.

<img width="1023" height="84" alt="image" src="https://github.com/user-attachments/assets/619332b8-fc53-4b19-8b94-a6614dadda51" />

Avataan zip.

    unzip ghidra_12.0.2_PUBLIC_20260129.zip

ls -komennolla nähdään, että Downloads -hakemistoon ilmestyy nyt uusi hakemisto **ghidra_12.0.2_PUBLIC**. Siirrytään siihen.

    cd ghidra_12.0.2_PUBLIC

Ghidra käynnistyy ajamalla tiedoston **ghidraRun**

    ./ghidraRun

## d) Nora CrackMe

[NoraCodes: crackmes](https://github.com/NoraCodes/crackmes)

CrackMe -tiedostot ovat tehtäviä, joissa pääse harjoittelemaan takaisinmallinnusta. Tehtävät saa aloitettua make <name> -komennolla. Niistä täytyy koittaa poistua status koodilla nolla, jotta tehtävä on suoritettu onnistuneesti. Lähdekoodia ei pidä lukea ettei pilaa tehtävää itseltä.
