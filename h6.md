# h6

## lataukset

Ladataan repositorio https://github.com/robbins/tp-link-decrypt

    git clone https://github.com/robbins/tp-link-decrypt

Uusi kansio ilmestyy kotihakemistoon. Siirrytään sinne.

    cd tp-link decrypt

Repositorion README -tiedostossa on ohje asentamiseen.

Ajetaan ensin tiedosto preinstall.sh, jotta on kaikki tarvittava asentamista varten.

    ./preinstall.sh

Ajetaan ohjelma extract_keys.sh, jotta saadaan RSA/DES -avaimet TP-Link Firmwaresta.

    ./extract_keys.sh

Suoritetaan make -komento.

    make

Tuli virheilmoitus:

<img width="1417" height="370" alt="image" src="https://github.com/user-attachments/assets/1b8651a4-d975-46a4-a038-a436acc2ff70" />

Virheilmoituksessa kerrotaan, ettei openssl/evp.h -tiedostoa tai -hakemistoa ole olemassa. Löysin Stack Overflowsta tähän vastauksen: [Fatal Error: openssl/evp.h No such file or directory](https://stackoverflow.com/questions/13024481/fatal-error-openssl-evp-h-no-such-file-or-directory)

Pitää asentaa libssl-dev -paketti.

        sudo apt install libssl-dev

Nyt tulikin useita virheilmoituksia MD5:teen liittyen

<img width="1413" height="898" alt="image" src="https://github.com/user-attachments/assets/41a891b6-72b0-45e0-8d44-2cd46e7f9fd4" />

Koitetaan kuitenkin jatkaa eteenpäin...

Hakemistoon ilmestyi lisää tiedostoja ja hakemistoja.

<img width="1281" height="197" alt="image" src="https://github.com/user-attachments/assets/c0bc7750-1251-461c-94d6-bf011e783650" />

Koitetaan ladata TapoV3 firmware binääri

        aws s3 cp s3://download.tplinkcloud.com/firmware/Tapo_C200v4_en_1.4.2_Build_250723_Rel.66773n_up_boot-signed_1754482060073.bin Tapo_C200v5_en_1.2.3.bin --no-sign-request

<img width="1403" height="215" alt="image" src="https://github.com/user-attachments/assets/0de9ab7d-0b9d-43f3-83c0-c8c3e183146e" />

Ei onnistunut, ehdotetaan asentaa libs3-2

        sudo apt install libs3-2

Tuli edelleen virheilmoitus:

        s3: unrecognized option '--no-sign-request'

Tarkistin onko aws -komentoa virtuaalikoneellani asennettuna.

<img width="946" height="210" alt="image" src="https://github.com/user-attachments/assets/1131a463-b2c2-4bd0-9f61-931f8c82b3e4" />

Ei ole, joten asennetaan --> yes

Sama virheilmoitus tulee edelleen. Tämä johtuu siitä, että komennosta puuttuu kohdehakemisto, johon tiedosto ladataan. Tarvitsee vain lisätä piste ladattavan tiedoston perään ([GeeksForGeeks (2025): Use high-level (s3) commands with the AWS CLI](https://www.geeksforgeeks.org/devops/cli-services-s3-commands/))

        aws s3 cp s3://download.tplinkcloud.com/firmware/Tapo_C200v4_en_1.4.2_Build_250723_Rel.66773n_up_boot-signed_1754482060073.bin Tapo_C200v5_en_1.2.3.bin . --no-sign-request

Tiedosto latautui kotihakemistoon.

Ladataan dump-tapo-c200c3-1.4.2.bin Moodlesta kurssin sivulta. Se ilmestyy Downloads -hakemistoon.

Siirretään tiedosto tp-link-decrpyt -hakemistoon.

        mv Tapo_C200v4_en_1.4.2_Build_250723_Rel.66773n_up_boot-signed_1754482060073.bin /home/sieni/tp-link-decrypt
